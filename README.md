# LangChain Model

A hands-on LangChain learning project covering LLMs, Chat Models, Embeddings, Hugging Face models, and Document Similarity.

## 📚 Topics Covered

### 1. LLMs
- Working with Large Language Models
- LangChain LLM integration
- Prompt-based text generation

### 2. Chat Models
- OpenAI Chat Models
- Anthropic Chat Models
- Google Generative AI
- Hugging Face API
- Hugging Face Local Models

### 3. Embeddings
- OpenAI Embeddings
- Document Embeddings
- Hugging Face Local Embeddings
- Document Similarity

## 🛠️ Technologies Used

- Python
- LangChain
- OpenAI
- Anthropic
- Google Generative AI
- Hugging Face
- Transformers
